The site you're looking at right now. Built to showcase my games and projects with zero
client-side framework overhead.

## Stack

- **Astro** for static generation and content collections
- **Tailwind CSS v4** via the official Vite plugin
- **MDX** for rich game write-ups
- **View Transitions** for SPA-like navigation
- **GitHub Actions** deploying to GitHub Pages on every push
